Hash Identifier

Guess the algorithm by shape

Paste a hash string. This tool ranks the likely algorithms by length and format: MD5, SHA-1, SHA-256, SHA-512, CRC32, bcrypt, argon2, NTLM, MySQL, and more. It reads the shape of the string, not its meaning, so results are candidates, not proof. Nothing leaves this page.

This is format-based heuristic identification, not verification. Different algorithms often produce the same length and character set (for example MD5, NTLM, and several others are all 32 hex characters), so many results are ambiguous by nature. The tool cannot confirm which algorithm actually produced a hash. Use the ranked list as a starting point.
